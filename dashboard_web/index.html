Data quality — a finding for the ops manager

The SLA flag doesn't match the numbers ⚠ audit source system

The export's sla_breached flag agrees with a recomputation (resolution_time > sla_target) only about half the time — no better than chance. Reporting uses the system-of-record field; this panel makes the gap visible rather than hiding it.

Recommendations for the ops manager
SLA data
The breach flag disagrees with the resolution times ~50% of the time.
→ Audit SLA at source before trusting breach reporting.
Staffing
Load is flat across weekdays, weekends & public holidays — no weekday peak.
→ Staff steadily seven days a week, not Mon–Fri.
Capacity
Demand is stable (~183/day); Q2 has 5 holidays → ~278 tickets per staffed day.
→ Baseline to the rate; pre-plan holiday cover for Q2 & Q4.
Data trust
Random measures, mismatched free-text, implausibly flat volume.
→ Treat as synthetic; validate on a real extract before acting.
