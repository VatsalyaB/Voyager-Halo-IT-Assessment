# Web dashboard (Part 2 — "or equivalent")

A self-contained, dependency-free dashboard for the TechSolve support data. Built as
the portfolio-friendly counterpart to the Power BI version (see `../powerbi/`).

## View it
- **Locally:** open `index.html` in any browser (works via `file://` — the data is a
  local `data.js`, no server needed).
- **Served / GitHub Pages:** publish the `dashboard_web/` folder; it's all static.

## What's inside
- `index.html` / `styles.css` / `app.js` — structure, theme, chart logic.
- `data.js` / `data.json` — pre-aggregated metrics (per value × year) generated by
  `../src/build_dashboard_data.py`. ~43 KB, so the page loads instantly instead of
  shipping 100k rows to the browser.
- `vendor/echarts.min.js` — charting library, vendored so the page has no CDN dependency.

## Features
- Reporting-period filter (defaults to **2024–2025** per the brief; toggles to all years
  / individual years) — rates and averages recompute client-side.
- Light/dark theme (remembers your choice); colours follow a CVD-validated palette.
- Sections: headline KPIs · volume & trend · ticket issues · status & time-to-resolution
  · **external data (NZ holidays / business days)** · team & region · **data-quality panel**.
- Table views under the key charts (accessibility + exact numbers).

## Regenerate the data
```bash
python ../src/build_dashboard_data.py   # rewrites data.js / data.json from the fact table
```
